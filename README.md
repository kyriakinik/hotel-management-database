# Hotel Management Database System

Εξαμηνιαία εργασία στο μάθημα **«Βάσεις Δεδομένων»**.

Το παρόν project περιλαμβάνει τη σχεδίαση, υλοποίηση και τεκμηρίωση ενός ολοκληρωμένου σχεσιακού συστήματος διαχείρισης δεδομένων για ξενοδοχειακή μονάδα (κρατήσεις, δωμάτια, πελάτες, προσωπικό, υπηρεσίες).

---

## 📁 Περιεχόμενα Αποθετηρίου

* **`HotelSystem.accdb`**: Η βάση δεδομένων υλοποιημένη σε **Microsoft Access** (πίνακες, σχέσεις, ερωτήματα/queries, φόρμες και αναφορές).
* **`Hotel Schema.sql`**: Το σχήμα και τα δεδομένα της βάσης (PostgreSQL Dump).
* **`REPORT_4059_3860.pdf`**: Η αναλυτική τεχνική αναφορά της εργασίας (ανάλυση απαιτήσεων, οντότητες/συσχετίσεις, σχεσιακό μοντέλο και κανονικοποίηση).
* **`EIKONES/`**: Διαγράμματα οντοτήτων-συσχετίσεων (ER diagrams) και σχεσιακά σχήματα της βάσης.

---

## 🛠️ Τεχνολογίες & Εργαλεία

* **RDBMS**: Microsoft Access, PostgreSQL
* **Σχεδιασμός**: Μοντέλο Οντοτήτων - Συσχετίσεων (ER Model), Σχεσιακό Μοντέλο (Relational Schema)
* **Γλώσσα Ερωτημάτων**: SQL (DDL, DML, DQL)
